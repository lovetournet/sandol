# SANDOL · 석산리노베이션 홈페이지 v2.1

브로슈어 톤(딥네이비/스톤그레이/화이트)을 바탕으로 만든 정적 홈페이지 초안입니다.
외부 프레임워크가 없는 HTML + CSS + JavaScript 사이트이며 Cloudflare Pages에 배포할 수 있습니다.

## 파일 구성

- `index.html`: 회사 및 제품 소개, 견적 요청 UI
- `css/style.css`: PC/모바일 화면 디자인
- `js/main.js`: 모바일 메뉴, 면적 계산기, 제품 선택, 견적 요청 내용 복사
- `images/`: 이미지·제품 콘셉트 그래픽
- `favicon.svg`: 임시 홈페이지 아이콘

## 실행

압축을 푼 다음 `index.html`을 브라우저로 열어 기본 화면을 확인합니다.
GitHub `lovetournet/sandol` 저장소의 최상위에 이 파일과 폴더를 업로드한 뒤
변경 사항을 커밋하면 연결된 Cloudflare Pages에서 자동 재배포됩니다.

## 제품별 견적문의

- 석재단열패널, 실내벽체단열패널, SPC 마루: ㎡ 또는 평을 입력하고 로스율을 적용
- 화장실 큐비클: `칸 수` 기준으로 문의
- **설치 지역(시·도 + 시·군·구)**: 모든 제품에서 필수 입력. 단열패널은 지역 및 현장별 사양 검토 안내 표시
- **견적 받는 분 성함·전화번호**: 필수 입력, 전화번호 형식 검증
- 업체명(선택), 제품 조건(선택), 추가 요청사항(선택) 입력
- 복사 내용에 설치 지역, 받는 분 성함·전화번호, 업체명이 함께 포함됨
- **복사 기능만 구현됨**: 입력값은 웹서버에 저장되거나 회사로 자동 전송되지 않습니다. 클립보드에 개인정보가 복사될 수 있으므로 공용 기기에서는 주의가 필요합니다.
- 실제 견적 전송 기능을 추가하려면 회사가 관리하는 별도 접수 시스템과 개인정보 처리·보안 검토가 필요합니다.
- 시·도 정보만으로 지역별 단열재·두께 또는 견적 금액이 자동 확정되는 기능은 제공하지 않습니다. 건축물 용도 및 설계 기준 등 조건을 담당자가 확인해야 합니다.

## 공개 전 확인사항

1. 기업 로고는 임시 벡터 심벌이므로 회사 공식 로고를 받으면 교체
2. 실내벽체단열패널·화장실 큐비클 이미지는 콘셉트 그래픽이므로 실제 제품 사진 확보 후 교체
3. 건축물 사진과 연구개발 사진은 브로슈어 제공 자료 기반 콘셉트입니다. 실제 시공·인증 실적과 혼동하지 않도록 확인
4. 회사 법인명, 주소, 대표자, 연락처, 제품 규격, 성능·인증자료, 법적 고지 및 영업 범위는 확인 후 게시
5. 현재 GitHub/Cloudflare 계정은 담당자의 개인 계정일 수 있으므로, 회사 도메인 구매 전 회사가 관리하는 계정과 소유 권한을 정리
6. GitHub 저장소가 Public 상태라면 비밀정보·비공개 계약서·고객정보 등을 저장하지 않음

## 운영 및 인수인계

- Cloudflare Pages는 연결된 GitHub `main` 브랜치가 변경되면 자동 배포
- 회사 명의 도메인 사용, 결제/갱신 회사 관리, GitHub 조직과 Cloudflare 접근 권한 분리 권장
- 로컬 백업 및 README/자료 인수인계를 유지
