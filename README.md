# SANDOL / SEOKSAN RENOVATION — V2.2 (HERO 업데이트)

## 변경 사항
- 사용자가 선택한 석산리노베이션 2026 브로슈어 표지 이미지로 메인 HERO 교체
- 이미 이미지에 문구가 포함되어 있어 텍스트를 중복으로 오버레이하지 않음
- 이미지 비율 유지: PC/모바일 모두 글씨 및 건축 이미지 잘림 방지
- 이미지 밑에 '제품 둘러보기' / '견적 문의하기' 링크 배치
- V2.1의 4대 제품군, 설치지역, 견적 받는 분 전화번호, 면적/칸 수 계산 기능 유지

## 올리는 법
1. 전체 파일을 확인합니다. `index.html`, `css/`, `js/`, `images/` 등이 필요합니다.
2. GitHub `lovetournet/sandol` → Add file → Upload files에서 압축 파일 자체가 아닌 **압축 해제한 폴더 안의 사이트 파일**을 올립니다.
3. 기존 `index.html`, `css/style.css` 등은 새 파일로 교체(덮어쓰기)합니다.
4. `HERO-section.html`, `HERO-section.css`는 붙여 넣기 참고 자료이므로 **사이트에 업로드할 필요가 없습니다.** (제거해도 됩니다.)
5. Commit changes 후 Cloudflare Pages가 연결되어 있다면 자동 배포 상태를 확인합니다.
6. 홈페이지에서 강력 새로고침(Ctrl+Shift+R) 후 메인 HERO와 견적문의 기능을 검토합니다.

## 이미지
`images/hero-seoksan-cover.webp` — 사용자가 제공한 브로슈어 표지를 웹용으로 압축한 이미지입니다.
원본의 문자/그래픽이 합쳐진 그림이므로 별도 HTML 텍스트로 편집할 수 없습니다.
회사 메인 사진은 콘셉트 이미지입니다. 실제 시공 사례로 표기하지 않습니다.

## 견적문의 주의
- 견적 요청 내용 '복사' 기능이며 서버 전송/개인정보 저장은 없습니다.
- 견적 받는 분 전화번호와 설치 지역 포함.
- 실제 견적 수신 기능을 연결할 때 개인정보처리 안내, 보안 전송, 수집 동의 등을 별도 준비해야 합니다.
