# sandol — 석산리노베이션 홈페이지 V2.3

현재 V2.2 HERO 이미지 및 V2.1 지역·연락처 견적 기능을 유지하며,
견적문의 옆에 **4페이지 브로슈어 슬라이더**를 추가한 버전입니다.

## 브로슈어 기능
- 파일: `images/brochure-01.webp` ~ `brochure-04.webp`
- 3초마다 1 → 2 → 3 → 4 → 1 순환
- 브로슈어 이미지 클릭: **일시정지 / 다시 클릭: 재생**
- 이전·다음 버튼 및 하단 점으로 수동 이동
- 일시정지 상태에서 수동 이동해도 그대로 일시정지 유지
- 움직임 최소화 설정을 사용하는 사용자는 자동 재생을 시작하지 않음
- 모바일에서는 견적문의 아래에 브로슈어 표시

## GitHub 적용
`index.html`, `css/style.css`, `js/main.js`, `images/brochure-01.webp` ~
`images/brochure-04.webp`를 GitHub 저장소의 **같은 경로**에 반영하세요.
V2.3 ZIP의 전체 파일도 함께 제공하므로 기존 파일 구조를 통째로 교체할 수 있습니다.

Cloudflare Pages가 GitHub `main` 브랜치와 연결되어 있다면 커밋 후 자동으로 재배포됩니다.

## 주의
- 견적 요청서는 **자동 전송되지 않으며 복사만** 하는 초기 시안입니다.
- 브로슈어는 사용자가 제공한 4장 이미지입니다.
- 현재 사용 중인 도메인, 실제 회사 자료 및 담당자 이메일은 공개 전 별도 확인하세요.
